# Repository review — 2026-09-29

## Scope

The review covered the Go service, configuration import/export, authentication
middleware dependencies, PostgreSQL configstore, Docker image, HA deployment
assets and the primary management UI shell. All executable checks ran in
Docker; no Go, Node, Python or scanner runtime was installed on the host.

## Fixed findings

| Severity | Finding | Resolution |
| --- | --- | --- |
| High | `pgx` 5.8.0 was reachable through a known placeholder-confusion SQL injection advisory | Updated to 5.9.2 and reran `govulncheck` |
| High | `gorilla/csrf` 1.7.2 contained broken Referer validation | Updated to 1.7.3; the application does not configure the separate unresolved `TrustedOrigins` path |
| High | Configuration import renamed live state before validating every ZIP entry | Added complete prevalidation for paths, types, duplicates, entry count and expanded size |
| Medium | FreeBSD/macOS metrics passed invalid bit sizes to `strconv.ParseFloat` | Changed all affected calls to 64-bit parsing and handled FreeBSD parse errors |
| Medium | Management pages disabled browser zoom and the main grouped navigation was mouse-only | Restored zoom, keyboard activation, focus indication and ARIA state |
| Medium | Default Docker documentation mounted the Docker socket directly | Removed the default mount and documented a restricted socket proxy for optional discovery |

## Verified checks

- `go mod verify`
- `go vet ./...`
- `go test ./...`

  and dynamic proxy packages
- full `go test -race ./...`
- `go build ./...`
- PostgreSQL schema/repository integration through
  `deploy/active-active/compose.test.yaml`
- `govulncheck ./...`: zero reachable symbol vulnerabilities after updates
- production Docker image build and standalone live/ready probes

## Known limitations

- `staticcheck@latest` still reports a pre-existing backlog dominated by Go
  1.26 deprecations, legacy style findings and dead code. It is not a green
  release gate yet; warnings were not suppressed to manufacture a pass.
- `govulncheck -show verbose` reports an unresolved package advisory for
  `gorilla/csrf` `TrustedOrigins`, but Zoraxy does not configure that option.
  It also reports the transitive, uncalled `x/crypto/openpgp` module advisory.
- The primary UI changes received static contract inspection only. No claim of
  complete WCAG compliance or cross-browser visual correctness is made.
- Active/active remains limited to the HTTP-routing revision domain. TLS,
  certificates, ACME, access rules, redirects, streams, users and plugins still
  use local state, as detailed in `deploy/active-active/README.md`.
- DRBD, Pacemaker, fencing, real Proxmox LXC and redundant L4 behavior require
  infrastructure acceptance tests; they cannot be proven by local containers.
